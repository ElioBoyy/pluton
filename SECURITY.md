# Security

Pluton runs on your own machine: its API and MCP server listen on localhost only, and API keys are stored encrypted in the local database.

## Reporting a vulnerability

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/ElioBoyy/pluton/security/advisories/new), never in a public issue. Include what is affected, how to reproduce it, and its impact. You will get an answer within a few days.

Only the latest commit on `main` is supported.
