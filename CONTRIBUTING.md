## Working on the code

- Node.js 22 or later, and pnpm (`corepack enable`).
- `pnpm install`, then `pnpm dev`, and open http://localhost:5173.
- Before opening a pull request, run `pnpm typecheck`.

The README's Contributing section lists the code conventions.
