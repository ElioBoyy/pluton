## Stack

Product app: Vite + React (apps/web). Marketing site: Astro (apps/site), static, with Astro i18n in the app's five languages (en, fr, it, es, de).

## What it is

Pluton is a go-to-market agent for B2B founders and small sales teams. Given a website (or two sentences), it builds a "Brain" of the company (ICP, personas, competitors, voice), turns plain-language ideas into Plays that find and score leads on a schedule, learns from the user's approve/reject verdicts, and runs LinkedIn and email sequences written in the user's voice. Nothing is sent without the user's review.

## Users and job

Founders who do their own sales, small B2B teams, agencies and GTM engineers, often already working with an AI agent (Claude Code, Claude Desktop, Codex). Job: find the right people and start real conversations without buying a lead database or hiring an SDR.

## Mechanism and position

- Signals first, free sources first: company registries, careers pages, tech detection, web search; paid sources only when a key is added.
- Every lead carries a fit score with the evidence behind it.
- The user stays in control: approvals before any message, budget caps on every search, an agent that asks before it acts.
- Works with the user's own AI: local MCP server for Claude Code, Claude Desktop and Codex.
- Runs hosted, or self-hosted from the GitHub repository (local SQLite, data stays on the user's machine).
